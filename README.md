# 🌤️ Descubra o Clima — App Meteorológico

Um aplicativo de previsão do tempo moderno, minimalista e dinâmico desenvolvido em **React**. O projeto consome dados em tempo real da OpenWeather API e adapta toda a interface do usuário (gradientes de fundo e elementos visuais) de acordo com o clima atual e o horário da cidade pesquisada.

---

## ✨ Funcionalidades

* 🔍 **Busca Avançada:** Pesquise o clima de qualquer cidade do mundo em tempo real.

* 🎭 **Fundo Dinâmico:** O plano de fundo do site muda automaticamente baseado no clima (calor, frio, chuva) ou se é noite na cidade
  selecionada.

* 💎 **Interface Glassmorphism:** Visual moderno utilizando efeito de vidro fosco com CSS avançado.

* 🎈 **Micro-interações:** Ícones flutuantes assíncronos e efeitos visuais fluidos na interface.

* 🚨 **Tratamento de Erros:** Feedback visual claro caso a cidade não seja encontrada ou ocorra falha de conexão.

---

## 🛠️ Tecnologias Utilizadas

* **React** (Componentização, Estados e Efeitos)
* **JavaScript (ES6+)**
* **HTML5 & CSS3** (Animações personalizadas e Flexbox)
* **OpenWeather API** (Consumo de dados HTTP via `fetch`)
